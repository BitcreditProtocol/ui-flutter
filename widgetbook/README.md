# bitcr_ui_widgetbook

The component catalog for `bitcr_ui`. A dev tool — it is never shipped.

```bash
dart run build_runner watch   # keeps main.directories.g.dart in sync
flutter run -d chrome         # or -d linux
```

If `-d chrome` reports no device, Flutter can't find a browser — see the
[repo README](../README.md), which also covers how to add a component and its
use cases.
